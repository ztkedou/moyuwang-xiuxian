# 摸鱼修仙传 · 更新日志

## [0.8.1] - 2026-09-28
### 问题修复
- 修复「交易行货款」在点击领取时灵石被重复计入两次的问题：现在领取多少就到账多少，不会再凭空多出一份
- 修复「宗门功法」在短时间内反复点击修习时，宗门贡献被重复扣除的问题：现在同一部功法并发修习只会成功一次，其余提示「已被抢先领悟」并原样退回贡献
- 修复「宗门功法」在云端存档同步的间隙里点击修习、宗门贡献被扣两次的问题：现在本地扣除带快照校验，已同步过就不再重复扣
- 修复「心法」等级显示比实际高出十倍的问题：此前练 1 级界面就显示 4 级、花 6000 灵石就显示「已满级」；现在显示等级与实际修习次数一致，练满需要与设定相符的灵石
- 修复「心法」在界面已显示「已大成」后仍能继续扣除灵石的问题：现在满级后不再接受进阶请求
- 修复「人物志」图鉴加成在数据异常时会连累整个游戏界面白屏的问题：现在加成读取失败只会暂时不计加成，游戏照常运行
- 修复云端存档保存失败时只重试网络类错误、遇到服务器自身写档失败（500）就直接报错的问题：现在服务端暂时无法保存也会自动重试，并区分「服务器正在更新」与「服务器繁忙」两种提示
### 体验优化
- 存档保存重试现在会遵循服务器给出的等待时间（Retry-After），服务器忙时不再盲目高频重推，减少不必要的请求
- 存档上传接口增加频率保护：正常游玩（自动存档约每 10 秒一次）不受影响，异常的高频刷档会被限流，避免服务器被拖垮
- 去掉了一处对 GitHub 的版本检查外联：此前每次版本更新后首次进入游戏，浏览器会去访问外部站点并在版本号比对不一致时强制刷新页面。现在版本号只从本站更新日志读取，不再外联、不再出现莫名刷新

## [0.8.0] - 2026-09-28
### 新增
- 「人物志」全面重做：新增可收集的人物图鉴（凡缘 / 仙缘 / 天缘 共 24 位），历练途中结识道友即可点亮，集齐后有永久修炼加成
- 宗门新增「功法阁」：四大阶位 × 三大流派共 12 部传承功法，可用宗门贡献逐层修习，修习后属性与战力即时生效
### 体验优化
- 新玩法入口不再藏在菜单底部：桌面端顶栏与移动端侧边抽屉均新增「新玩法」置顶分组（通天塔 / 灵兽远征 / 万宝洗炼 / 自创神通 / 交易行货款），抽屉开关加了「新」角标提示
- 信箱新增「一键领取」：一次领完全部未领取的附件邮件
- 限时活动现在会显示详细说明，活动名与类型名重复时不再重复显示
- 主界面版本号改为随更新日志自动同步，不再固定显示旧版本
- 存档保存失败时的提示更准确：服务器更新期间会自动重试并提示「服务器正在更新」，不再一律误报为网络问题
### 平衡调整
- 「心法」数值重规划：同品级同门槛的心法强度拉齐，属性改为随境界成长，多修心法收益递减，修炼速度加成设有上限——「精选搭配」取代「无脑全学」
- 「自创神通」基础系数收敛并增设上限，参悟成长由每重 ×1.12 降为 ×1.06，避免多门神通叠加后属性溢出
- 「万宝洗炼」特殊词条（会心 / 裂魄 / 幻影 / 噬灵）按档位缩放并设置战斗层总上限，洗炼灵石消耗上限由 1 万提高到 4 万
- 「通天塔」每日扫荡奖励与首通曲线对齐（统一取首通的 30%），此前扫荡收益远低于设计预期

## [0.5.0] - 2026-09-28
### 新增
- 全新玩法「九天通天塔」：逐层挑战守塔者，首次通关可领破关奖励，每日还能一键扫荡已通关层数
- 全新玩法「灵兽远征」：派遣灵兽前往秘境探险，到点领取灵石、丹药与材料
- 全新玩法「万宝洗炼」：为装备开炉洗炼、重铸道蕴词条，可锁定满意的词条后再洗
- 全新玩法「自创神通」：融合两本功法参悟独门神通，可继续参悟提升威力，也可遗忘返还部分灵石
- 交易行新增「交易行货款」：自己上架的物品被买走后，货款会先妥善托管，可随时一键领取
- 新增的玩法都能在顶部「仙务」与侧边抽屉菜单里直接进入
### 平衡调整
- 洗炼与神通带来的属性加成会真正作用于战斗：会心、暴击伤害、闪避、吸血、伤害减免均已生效
### 问题修复
- 修复交易行物品售出后卖家收不到货款的问题
- 修复交易行商品在链接带有重复前缀时无法购买或下架的问题
- 修复交易行商品卖家一律显示为「系统」、无法看出真实卖家的问题

## [0.4.0] - 2026-09-27
### 新增

- 更新日志会随每次更新实时刷新
### 平衡调整
- 各玩法的灵石奖励改为随境界提升：境界越高，同样的玩法给得越多
- 已调整的玩法：爬塔与秘境、日常任务、宗门任务、宗门晋升、接任宗主、成就、图鉴、出售物品、放生灵宠、抽奖、离线收益

### 体验优化
- 更新日志面板会自动只保留最新 1000 条。日志满了也会继续显示新内容，最早的记录被自动覆盖，不再需要手动清理
- 补充多处功能的灵石消耗提示，现在能提前看到要花多少：妖灵喂养、灵田种植、挑战宗主、悬赏发布
### 问题修复
- 修复多处功能只显示名称、不显示灵石消耗，导致不清楚要花多少灵石的问题
