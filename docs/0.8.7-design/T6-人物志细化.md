## 2. 统一设计决策（七条）

1. **服务端零改动**（§1.3），全部落在前端第 18+ 号新模块 `yl_t6chardex_ext.py`（`V28_MODULES` 由架构师统一接线：fun086 后、numbal 恒最后；与 act087/t7sect/t8mentor 新模块互不重叠锚点）。实现员只改模块源文件+自检，**不跑 build/dryrun/sandbox**。
2. **数据只追加不迁移**：`player.charDex` 加 `v:2` 与 `demands`（§7）；v1 老档缺字段懒初始化，`met/claimed/bond` 原样保留——老玩家图鉴进度、已领奖励零丢失。
3. **客户端权威不变**：需求扣物/奖励发物都在客户端入账（与自由赠送、`mile.item` 同心结、成就同一信任级别），不新增风险面。
4. **两列布局沿用 F6 产出物的既有 CSS 类**：`grid grid-cols-1 md:grid-cols-2 gap-4 items-start`（该完整串基线**恰 1 处 @254408**，属上游某页；F6 融合壳用的是不带 items-start 的组合——门禁按「基线+1」断言，见 §10.1-③）+ 外壳 `containerClassName:"md:max-w-6xl bg-paper-800 border-stone-600"`（**照抄 F6 壳 @900334 的同一串值**；注意无空格形态 `containerClassName:"md:max-w-6xl` 基线已恰 1 处 @1054615 = F6 的 `wN` 融合壳 ⇒ 门禁断言「改后 = 2」，不是 1）。**不接 `xw` 融合键**——`xw` 语义是「左列=仙务块」，人物志左列要放图鉴本体；故只**沿用 F6 的两列视觉模式**（同一 grid 类、同宽外壳、`min-w-0` 防溢出、不用 sticky）。★ 改模态外壳必须用互斥三元/属性注入，不得并列两个 max-w 类（CSS 输出顺序裁决，SKILL §22.2 / DEPLOY_LOG_0.8.6 §1.2 同坑）。
5. **数值已定档**（《数值表-T5T6》§3，2026-09-29 数值批；原 [数值待定] 占位均已回填定值）；全部集中在新表 `YLXW_CHAR_DEMAND_POOL / YLXW_CHAR_DROP_N / YLXW_CHAR_DROP_RAR` + 两常量（好感加值、历练概率），调参不动逻辑。
6. **EV/红线核对**：铁律②（EV≤1）不触发——本案**零新增赔率型玩法**（无下注、无中奖概率对价）：「随机物品掉落」是里程碑一次性奖励的**形态变化**（定值→随机物品），产出价值锚定由数值策划师对照旧表（灵石/修为×rf）定档，且次数天然受「里程碑一次性 + 缘契上限 100 + 图鉴 24 位」封顶；「历练低概率」是**下调**产生频率，只减不增。需求提交=物品换好感，双向对价、无灵石回流。
7. **断言打在独有信号上**（铁律⑥）：需求卡用 `demands[npcId].need` 渲染信号、掉落用背包物品名增量、历练概率用静态份数断言 + 沙盒统计对照，不碰 `#modal-title` 等共享信号。

## 4. ② 砍自由赠送 → 任务式「师门求物」

### 4.1 玩法规则

- 每位**已结识**道友（含无名道友）持有一条**当前需求**：从其稀有度对应的需求池随机一种物品 × 需求数量（§4.2）。
- 详情页渲染「求物卡」：`他想找【回春丹】×3（已备 1/3）`；背包足量时 [交付] 亮起 → 扣物品 → 好感 +3/+5/+8（按 NPC 稀有度：凡缘 +3 / 仙缘 +5 / 天缘 +8，已定档，验算见《数值表-T5T6》§3.1）→ 立即重掷新需求。图鉴内 24 位按 `YLXW_CHAR_DEX` 的 rarity 取池；**无名道友**（动态 id，不入图鉴）一律按凡缘池。
- **默认赠送**：求物卡旁保留 [赠灵石]（沿用 `YlxwGiftCost` 现行费用曲线 `2^(F/40)` 不动），好感收益 5 → **+2**（任务书写明「默认赠送灵石好感+2」；定档 +2——纯送礼满好感成本 51,452→132,054 灵石 ×2.57，《数值表-T5T6》§3.1）。改点唯一：`YlxwGiftCost(j&&j.favorability),E=5` → `…,E=2`（恰 1 @1529719，两处按钮消费同一回调）。
- **砍自由赠送**：删除「赠送」按钮 + 背包挑物浮层（picker 整块，含唯一 `Recipe"` 过滤串 @1528960 与「赠送」按钮 @1533448），好感获取从「无限自由投喂」收敛为「每日重掷的一条需求 + 灵石兜底」。
