## 0. ★ 一页结论（先给判断）

### 0.1 现状真相：分诊文档的「几乎不存在」结论**有误**，真实情况是「**骨架完整、玩法层残缺**」

### 0.2 玩法定位（★ 需用户拍板的核心取舍）

> **定位：PVE 为主（试炼塔）+ 异步 PVP 为辅（论剑台，保留并补「快照挑战」）。**

理由（本作是**单机为主 + 弱联网**的修仙挂机游戏）：
1. **同步真人对抗不可行** —— 无实时通信通道、无匹配池、对手是否在线不可控。
2. **纯异步真人对抗同样不可靠** —— 现有擂台要求「对方在页签点应战」，但本作玩家多为独狼/低频在线，**下战书大概率石沉大海** ⇒ 这就是「功能事实上死亡」的第一病根（§1.2 P1）。
3. ⇒ **主力玩法必须是纯 PVE 试炼**（随时可玩、零等待、零对手依赖），把真人对抗降级为**社交彩蛋**。
4. **「快照挑战」根治 PVP 死结**：直接挑战榜单上任意玩家的**战力镜像快照**（取 `rankings.combat_power`），**对方无需在线、不受损失**（只收一封战报），立即结算。这一步把 PVP 从「依赖对方」变成「依赖数据」。

**取舍点（报用户拍板）**：
- **A. 玩法定位**：是否接受「PVE 试炼为主 + PVP 论剑为辅」（本文方案）？还是**砍掉 PVP**只做纯 PVE？还是**保留纯 PVP**只补玩法说明？
- **B. 战斗表现**：默认**快速结算**（战力加权随机，挂机节奏）还是默认**回合制观战**（复用 `isTurnBasedBattleOpen` 引擎，有观赏性但打断挂机）？本文默认「快速结算 + 可选观战」。
- **C. 段位/周榜**：是否需要段位与周榜（本文给了，但单机为主时榜可能稀疏）？

### 1.3 结论：**服务端小改（加快照+积分）+ 客户端页签重做（三区分栏）+ 新增试炼玩法**

1. **服务端 = 改造**：现有守卫式写法（频控 + 唯一约束 + 邮件通知 + 白名单）完全符合本项目纪律，**推倒重做只会丢防线**。缺的只有：① 试炼（新表+新端点）；② 快照挑战（复用 `arenaSettrol` 抽公共结算）；③ 积分/段位（加列）；④ 活跃度埋点（写 `daily_quests`）。
2. **客户端 = 页签重做**：现有 `YlxwTArena` 是单页平铺，改成**三区分栏**（试炼 / 论剑 / 恩怨），并补「玩法说明」折叠块。
3. **新增玩法 = 试炼塔**（本文核心增量）。

### 3.2 分栏一 · 试炼（PVE，★ 新增，主力玩法）

**关卡结构**
- 按境界分 **7 大关**（炼气 / 筑基 / 金丹 / 元婴 / 化神 / 合道 / 长生），每关 **9 小层**（对应 `realmLevel` 1~9）⇒ 共 **63 层**。
- 解锁：**第 N 关需玩家境界 ≥ 该关境界**（炼气期即可进第 1 关）；层内**逐层解锁**（通关第 k 层才开第 k+1 层）。
- 层标记：**第 3 / 6 / 9 层为「精英层」**（`精英` 标记，奖励 ×1.5），第 9 层为「守关层」（沿用精英标记，文案称「守关」）。

**对手生成（NPC）**
- 名字池：按境界取风格化 NPC 名（如炼气关「张三丰」…长生关「太虚剑尊」），**同一层名号固定**（可反复挑战、可记忆）。
- 属性：按 §5.1 公式由 `Cs[realm]` 基础属性 × 层系数生成，**无随机浮动**（同一层每次进都是同一组属性 ⇒ 可策略化、可攻略、可复现）。
- 8 属性齐上（`attack`/`defense`/`maxHp`/`spirit`/`physique`/`speed` + 派生 `critRate`/`crit`/`dodge`/`hit`/`luck`/`vampire`）⇒ 同时为 item 1「属性面板补全展示」提供落地面。

**次数与重置**
- 免费挑战：**每日 5 次**（北京 0 点重置；★ 日切口径待拍板，见 §3.5.3 与清单 I）。
- 可购买额外次数：**每日最多买 2 次**，第 1 次 `floor(2000×1.5^r)` 灵石，第 2 次 `floor(4000×1.5^r)` 灵石。
- 失败**不消耗次数**（鼓励挑战高难层）；胜利才扣 1 次。
  > 取舍点 D：也可选择「失败也扣次数」增加紧张感，但单机为主建议宽松。

**胜负判定（D4 双模式）**
- **快速结算（默认）**：复用 `arenaResolve` 思路 —— 双方各 `战力 × (0.7 + rand×0.6)` 比大小。试炼中「我」= 玩家实时 `combat_power`，「敌」= 由 §5.1 属性反算的战力。
- **回合制观战（可选）**：复用 `isTurnBasedBattleOpen` + `turnBasedBattleParams`（产物已存在，@540470/@543026）把同一场战斗以回合制回放展示；**结算结果与快速结算一致**（避免两套判定不一致）。
- ★ **实现建议**：先只做快速结算（成本最低），回合制观战列为 P2 增强。

**奖励（三层）**
| 层 | 触发 | 公式 | 性质 |
|---|---|---|---|
| 单次胜利 | 每次通关 | `floor(150 × M(r) × (1 + (layer-1)×0.08))` 灵石 | 可重复（受次数限制） |
| 每日首胜 | 当日第一次胜利 | `floor(800 × M(r))` 灵石 | 每日 1 次 |
| 三连胜 | 当日累计 3 连胜 | `floor(1200 × M(r))` 灵石 | 每日 1 次 |
| 首通 | 该层首次通关 | 灵石 `floor(500 × M(r) × layer × (精英?1.5:1))` + 修为 `floor(0.05 × realmMaxExp(r,layer) × (精英?1.5:1))` | **一次性**（每层仅一次） |

其中 `M(r) = 1.5^r`（`r` = 境界序 0~6），`realmMaxExp(r,layer) = floor(maxExpBase[r] × (1+(layer-1)×0.24))`（服务端 `realmMaxExp()` :3882 同源）。

### 3.3 分栏二 · 论剑（异步 PVP，改造现有擂台）

**保留（不动）**
- 下战书：手填对方名号 → `POST /api/arena/challenge`，**3 次/日**（`ARENA_DAILY_MAX`）。
- 应战 / 谢绝 → `POST /api/arena/accept` / `/decline`。
- 胜者：声望 +10（`ARENA_RENOWN_WIN`）+ 灵石 `floor(3000×1.5^r)`（`ARENA_STONE_BASE`）；败者入仇人名单。
- 战报历史、声望榜（`renownTop`）。

**新增 A · 快照挑战（★ 根治 P1）**
- 在「论剑」分栏展示**战力榜 TOP20**（`rankings` 按 `combat_power DESC`，服务端已有该排序索引 `idx_rankings_combat` :199）。
- 点任意玩家 → 「快照挑战」→ 以该玩家的**战力镜像**为对手立即结算（`arenaResolve` 复用）。
- **对方无需在线、不受任何损失**（不加其败场、不进其仇人名单），仅收一封「XXX 向你发起快照挑战」的战报邮件。
- 次数：**每日 5 次**（新增 `ARENA_SNAPSHOT_MAX=5`）。
- 积分：**只有快照挑战与下战书结算计入积分**（见下）。

**新增 B · 积分与段位**
- 新列 `arena_points`（`rankings` 表加列，或新表 `arena_scores`）。
- 积分规则：
  | 情形 | 积分变化 |
  |---|---|
  | 胜（同段或低段） | `+12`（4~7 段 `+14`，见 §5.4 表） |
  | 胜（对手**段位更高**） | 额外 `+6`（4~7 段 `+7`）—— 越级挑战加成 |
  | 负 | `-5`（4~7 段 `-6`） |
  | 积分下限 | `0`（不为负） |
- 段位 7 段（§5.4），**随积分实时升降**（可掉段）。

**新增 C · 周榜**
- 结算：**每周一 00:00（北京）**按 `arena_points` 排名（复用服务端 `bjDate` 思路扩展为周）。
- 奖励（邮件发放）：
  | 名次 | 奖励 |
  |---|---|
  | 第 1 名 | `floor(20000 × M(r))` 灵石 + 称号「太虚魁首」 |
  | 第 2~3 名 | `floor(12000 × M(r))` 灵石 |
  | 第 4~10 名 | `floor(6000 × M(r))` 灵石 |
  | 参与奖（本周 ≥ 10 场） | `floor(2000 × M(r))` 灵石 |

#### 3.5.1 为什么以 T9 为准（本会话实测复核，c2 的诊断成立）

- 现有 `tickDailyQuests`（:5045）**只吃 `POST /api/save` 的存档差值** —— 全产物仅 2 个调用点（:2151 / :2174，均在存档上传处理器内），入参来自 `computeQuestDeltas(prevCounters, extractCounters(saveData))`（:3840）。⇒ **任何「不由客户端存档计数器派生」的进度都加不进去**，这正是「活跃度项目加不上去」的根因。
- 现有 4 项 `QUEST_DEFS` 恰好全部可由存档计数器派生（`playTime`/`killCount`/`adventureCount`/`spiritStones`）。
- **本项目已有「读时惰性推导」的成功先例**：Y19 成就系统注释明写「达成状态从 `stats_daily`/`daily_quests`/`saves` **惰性推导（Y19 零新增埋点零新增统计表）**」（:4162、:9636-9637）。
- ⇒ c2 主张的「`/api/quest/summary` 内读时 COUNT」在架构上更优：零写埋点、天然幂等、不需要每个子系统改结算逻辑。**本文认同。**

#### 3.5.2 演武场侧需要暴露的接口（本文的交付部分）—— ✅ **已定：只计论剑**

c2 的读时 COUNT 需要「今日论剑场次」。**现有 `arena_battles` 表结构不变**，读法（**c2 已复核采纳，原样写入 T9 §5.3**）：

```sql

SELECT COUNT(*) AS c FROM arena_battles
 WHERE (challenger_id = ? OR defender_id = ?)
   AND status = 'accepted'                 -- ★ 必须过滤：accept(:8604) 与 decline(:8631) 都写 resolved_at
   AND resolved_at >= ?                    -- 日切基准，见 §3.5.3
```

**决议（2026-09-29 c2-design 拍板，采纳本文建议）：只计论剑，不计试炼/快照。**
- 本文新增 `arena_trials`（试炼）与 `arena_snapshots`（快照挑战）为**两张独立新表**（T16 §6.1），**不改 `arena_battles` 结构** ⇒ 满足 c2「表结构不变」约束，**演武场侧真·零改动**。
- 3 次/日 与现有 `ARENA_DAILY_MAX=3` 恰好对齐 ⇒ 与 T9「擂台论道 3 次 × 7 分」自然对应。

#### 3.5.3 ★ 日切口径不一致（既有问题）—— ✅ **c2 已选方案甲，但仍需用户拍板**

实测：**同域内存在两套日切基准**，且现有竞技场用的是**非北京**口径（行号已按当前产物 md5 `02bfb414…` 复核，未漂移）：

| 系统 | 日切 | 证据 |
|---|---|---|
| `daily_quests` / `stats_daily` / 成就 | **北京 0 点**（`bjDate()` :3823） | :3823-3825 |
| **现有竞技场下战书配额** | **UTC 0 点**（`utcDayStartMs()` :7962 = `setUTCHours(0,0,0,0)`） | :8543、:8576 |
| 师徒传功 / 好友送礼 | UTC 0 点 | :7851、:8033、:8059 |

**两案与结论**：
- **方案甲（★ c2 已选、本文推荐）**：新增 `bjDayStartMs()` 辅助，**演武场全部日切（含新增试炼/快照）统一北京 0 点**，并把现有 `ARENA_DAILY_MAX` 的 2 处 UTC 日切（:8543/:8576）一并改北京 —— **小改 2 行**，消除同域双口径；玩家感知一致（复仇窗口「北京 19-22 点」本就是北京口径）。

## 8. ★ 玩法说明（玩家可见文案，面板「玩法说明」折叠块全文）

> **演武场是修士磨砺身手的地方**：想练手就打「试炼」闯关，想比划就上「论剑」切磋，结下的梁子到「恩怨」里了断。
>
> **【试炼 · 闯关】**
> - 按境界分七关（炼气 → 长生），每关九层，共 **63 层**；通关第 k 层才解锁第 k+1 层。
> - 每层的对手**实力固定**（同一层每次进都一样），可以反复研究打法；第 3、6、9 层是**精英层**，奖励 ×1.5。
> - 每天免费挑战 **5 次**，胜利才扣次数，失败不扣；次数不够可花灵石购买，**每天最多买 2 次**。
> - 奖励：每次胜利得灵石；每天**第一次胜利**有额外奖励；当天拿到 **3 连胜**再领一笔；每层**首次通关**有丰厚的一次性奖励（灵石 + 大量修为）。
> - 每天 0 点（北京时间）重置次数与首胜、连胜进度。
>
> **【论剑 · 切磋】**
> - **下战书**：输入对方名号发起挑战，每天最多 3 次；对方在论剑页看到后可以「应战」或「谢绝」。胜者得声望与灵石，败者会被记上一笔仇。
> - **快照挑战**：不想等人应战？直接在战力榜上点一位道友发起**快照挑战**——系统按他的战力镜像与你交手，**他不用在线、也不会有任何损失**，你立刻就能打完。每天 5 次。
