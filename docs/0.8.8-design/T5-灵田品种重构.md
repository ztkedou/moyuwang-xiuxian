# T5 · 灵田品种重构与扩容 策划案（0.8.8 批次 · C 组）

> **来源**：用户 2026-09-29 需求 item 5（原文）：
> 「仙务·灵田中可种植品种重构以及数量增加，成熟后变成"变卖"和"服用"两个按钮，变卖获得灵石，这一类数量要跟品阶对应，越高阶卖价越高。"服用"增加修为和属性的小幅度提升，每一种作物可以略微增加2-3种属性，总体规划按照属性和修为都增加，增加基础属性的灵草所需时间相对较短。增加百分比属性如命中、暴击、闪避、吸血这类有上限稀有的属性，灵草需要很高等阶并且收获时长比较长。也设计单独只增加修为的灵草和专门用于卖钱的灵草。你用游戏策划师来详细策划一下。」
> **基线**：线上 0.8.7（客户端 `build/assets/index-v287-20260929.js` / 服务端 `srv/index_v28.ts`）。
> **现状口径来源**：《T9T10-洞府灵田.md》§1.3（灵田现状照录）+《数值表-T9T10.md》§3（作物现值）+ 0.8.7 服务端 `[farmcore]` 常量块（`srv_patch_t10_farm.py`）。
> **本文只做策划，不含任何代码改动**。数值为**策划建议值**，进实现前须走 `tools/_t5_calc.py` 复算（体例同 T9T10）。
> ★ **重要边界**：本文件的「变卖 / 服用」**不是真实物品**（用户明说名字可随意取，不进背包、不进物品表）。**洞府自带灵草**才是游戏内真实道具（item 6 的事，本文不涉及，设计时勿混淆）。
> ★ **本文为策划案：所有「已定义 / 已重排 / 改为 Y」均为「方案已定、尚未实现」，代码一行未动，实现批须逐条自行落地。**

## 0. 一页结论

| 项 | 现状（0.8.7） | 本案（0.8.9 建议） |
|---|---|---|
| 品种数 | **5 种**（灵草/灵芝/千年参/太虚果/造化青莲），单一「种→等→收」 | **20 种**（5 品阶 × 4 产品线） |
| 收获动作 | 直接结算「灵石 + 修为」 | **二选一按钮**：**变卖**（灵石）／**服用**（修为 + 属性） |
| 成熟时长 | 240 ~ 4,320 min（最基础 **240**） | **120 ~ 1,440 min**（最基础 **120**，**整体下调**，配合 item 4） |
| 品阶分层 | 无（5 种平铺） | **凡品 / 灵品 / 玄品 / 仙品 / 神品**（5 档） |
| 产品线 | 无（都是「灵石+修为」） | **① 综合草**（修为+2~3 基础属性）／**② 纯修为草**／**③ 纯卖钱草**／**④ 稀有百分比草**（玄品+） |
| 变卖价曲线 | 800 / 5,000 / 25,000 / 70,000 / 215,000（随作物） | **500 → 27,000**（纯卖钱草，随品阶 ×2.1~3.3）；全表最高 27,000 |
| 百分比属性 | 无 | **暴击/闪避/命中/吸血**，**有硬上限**（+8%/+6%/+8%/+4%），仅 **玄品以上 + 长时长（720~1,440 min）** |
| 经济红线 | 满配 ≤ 150,000 灵石/日（T9T10 定档） | **满配 117,612 灵石/日 ≤ 150,000**（余量 **21.6%**）✅ |
| 修为产出 | 满配 ≈ 258,000 修为/日（造化青莲折算） | 满配 ≈ **182,400 修为/日**（纯修为草神品折算，**0.71×**，按 T7 §3.5 铁律主动收紧「灵石→修为」通道） |

**一句话**：把灵田从「5 种作物的单循环」重构为 **5 品阶 × 4 产品线 = 20 种作物**的**双出口（变卖/服用）**体系，属性线覆盖**基础属性（短时长）→ 百分比稀有属性（高品阶 + 长时长，有上限）**，并保住既有经济红线。

## 2. 品种体系设计

### 2.1 品阶分层（5 档）

| 档 | 名称 | 定位 | 解锁（洞府等级，复用 T9 档） |
|---|---|---|---|
| 1 | **凡品** | 新手入门，快循环 | 无（Lv1） |
| 2 | **灵品** | 主力产出 | 无（Lv1） |
| 3 | **玄品** | 中期，稀有属性起点 | **Lv3** |
| 4 | **仙品** | 高阶 | **Lv5** |
| 5 | **神品** | 终局 | **Lv7** |

> 解锁门槛**复用 T9 洞府等级档**（Lv3/Lv5/Lv7 与 T10 地块门槛 L5/L7/L9 错位，避免「同一门槛卡两件事」）。

### 2.2 四条产品线

| 线 | 名称 | 产出 | 时长特征 | 变卖价特征 |
|---|---|---|---|---|
| ① | **综合草** | 修为 + **2~3 种基础属性** | 中（1.5×基准） | 中 |
| ② | **纯修为草** | **只给修为**（无属性） | 中偏长（1.25×） | 低 |
| ③ | **纯卖钱草** | **只给灵石**（服用只给微量修为） | **最短**（1.0×） | **最高** |
| ④ | **稀有百分比草** | 修为 + **1~2 种百分比属性**（有上限） | **最长**（2.0×） | 中低 |

> 与用户原话对应：① = 「属性+修为综合草」；② = 「单独只增加修为的灵草」；③ = 「专门用于卖钱的灵草」；④ = 「百分比属性…需很高等阶并且收获时长比较长」。

### 2.3 成熟时长（★ 基准 120 min）

**品阶基准时长 B（= 纯卖钱草）**：

| 品阶 | 凡品 | 灵品 | 玄品 | 仙品 | 神品 |
|---|---:|---:|---:|---:|---:|
| B（min） | **120** | 180 | 300 | 480 | 720 |

**类型系数 k**：纯卖钱草 `1.0` / 纯修为草 `1.25` / 综合草 `1.5` / 稀有百分比草 `2.0`

**时长 = B × k**（取整到 30 min 倍数，**下限 120**）：

| 品阶 | 纯卖钱草 | 纯修为草 | 综合草 | 稀有百分比草 |
|---|---:|---:|---:|---:|
| 凡品 | **120** | 150 | 180 | — |
| 灵品 | 180 | 240 | 270 | — |
| 玄品 | 300 | 360 | 450 | **600** |
| 仙品 | 480 | 600 | 720 | **960** |
| 神品 | 720 | 900 | 1,080 | **1,440** |

- **全表范围 120 ~ 1,440 min**（现状 240 ~ 4,320）→ **整体下调**，最长项降到现状的 **1/3** ✅
- **设计意图**：基础属性草（综合草 180~1,080）**明显短于**稀有百分比草（600~1,440）✅ 符合用户「基础属性草时长较短 / 百分比属性草时长较长」。
- 生成规则（可机检）：`时长 = clamp30( B(品阶) × k(类型) )`，如 灵品综合草 `180 × 1.5 = 270`、玄品稀有草 `300 × 2.0 = 600`、神品稀有草 `720 × 2.0 = 1440`。

### 2.4 变卖价曲线

**品阶基准价 V（= 纯卖钱草变卖价）**：`500 / 1,500 / 5,000 / 13,000 / 27,000`（凡→神，逐档 ×3.0 / ×3.3 / ×2.6 / ×2.1，**严格递增**）

**类型系数 m**：纯卖钱草 `1.0` / 综合草 `0.6` / 稀有百分比草 `0.5` / 纯修为草 `0.2`

**变卖价 = round(V × m)**；**种子价 = round(变卖价 × Cs)**，`Cs`：纯卖钱 `0.70` / 综合 `0.50` / 稀有 `0.56` / 纯修为 `0.50`

> ★ **必须保留种子成本**：若种子免费，则「变卖价 = 净收益」，满配日净会直接突破红线。种子成本是红线成立的**前提**（见 §5）。

### 2.5 服用效果

**A. 修为**（`服用` 给）：
- **纯修为草**：`150 / 470 / 1,450 / 4,500 / 19,000`（凡→神）—— **已按 T7 §3.5 铁律单独下调**（见 §5.6）
- **其余三线**：品阶基准 `E = 100 / 400 / 1,500 / 5,000 / 15,000`（凡→神）× 类型系数（综合草 `1.0` / 稀有 `0.5` / 纯卖钱 `0.2`）；**仅综合草 玄/仙 因保序微调**为 `1,400 / 4,400`（原 `1,500 / 5,000`）

> ★ **铁律自查（T7 §3.5，用户 2026-09-29 拍板）**：灵田「服用」原本在**纯修为草**一条线上出现「灵石→修为」**正套利**（按 T7 §3.5 口径 B，炼气期折打坐 1.79× 折挂机），违反铁律。**只下调纯修为草**（其余三线天然合规，比值 ≤0.34），并把**综合草 玄/仙 微调**以保住 §4.3 的 `纯修为 > 综合 > 稀有 > 纯卖钱` 保序。完整四步法复算 + **口径 A/B 对照**见 **§5.6**。

**B. 基础属性**（综合草专有）：**每项**点数 `A = 8 / 30 / 100 / 350 / 1,000`（凡→神），每种综合草给 **2~3 项**（具体项见 §3 表）

**C. 百分比属性**（稀有草专有）：

| 品阶 | 单次加成区间 | 说明 |
|---|---|---|
| 玄品 | **+0.3% ~ +0.5%** | 稀有属性起点 |
| 仙品 | **+0.6% ~ +1.0%** | |
| 神品 | **+1.0% ~ +1.5%** | 最高档 |

**★ 百分比属性硬上限（灵田「服用」来源累计）**：

| 属性 | 上限 | 说明 |
|---|---:|---|
| 命中率 `hitRate` | **+8%** | 达到上限后服用不再增加该项（按钮置灰 + 提示） |
| 暴击率 `critRate` | **+8%** | |
| 闪避率 `dodgeRate` | **+6%** | |
| 吸血率 `vampire` | **+4%** | |

> 上限是**独立于装备/称号的「灵田专有加成上限」**（即：灵田最多给到上表数值，装备另计）。这样既满足「有上限稀有」，又不与 item 1 的属性面板总账打架。

## 4. 公式与抽样验证

### 4.1 公式汇总

```
时长(min)      = clamp30( B(品阶) × k(类型) ),  下限 120
变卖价(灵石)   = round( V(品阶) × m(类型) )
种子价(灵石)   = round( 变卖价 × Cs(类型) )
净/茬(灵石)    = 变卖价 − 种子价
日净/田(灵石)  = 净/茬 × 1440 / 时长
服用·修为      = 纯修为草取 §2.5-A 直表；其余三线 = round( E(品阶) × e(类型) )
服用·基础属性  = A(品阶)  每项，2~3 项
服用·百分比    = 见 §2.5-C（含上限）
满配日净/田    = 日净/田 × (1 + 洞府加成 + 照料加成) = 日净/田 × 1.21
```

### 4.2 抽样验证（手算 3 例，全部核对）

| # | 作物 | 计算 | 结果 | 与表一致 |

### 5.5 与现状的红线口径差异（诚实声明）

- 0.8.7 的 120,300 是「松弛上界」（6 田全种最赚作物）。本案的 117,612 是**同一口径**（6 田全种最赚作物 = 纯卖钱草神品）。
- 本案**未叠加**轮作衰减 / 虫害（与 0.8.7 同口径，属松弛上界）；实际收益只会更低。
- **若采纳 §7-Q3 的「照料每次 +2%、当日累计 +10%」**，则满配乘区仍是 ×1.21，红线结论不变 ✅。

### 5.6 ★ 铁律自查：T7 §3.5「直接升级须付巨大代价」适用性（**已按口径 B 落地**）

> 铁律原文（用户 2026-09-29 拍板，见 T7 §3.5）：「本游戏升阶消耗较长，以后所有能直接升级的功能都要付出巨大代价」⇒ 凡能**直接**提升等级/段位/境界/属性的功能，其获取代价必须巨大到正常玩家无法靠游戏内资源稳定获得。

**判定法（T7 §3.5 判定式 / §3.4.4）**：`P ÷ H ≥ G`，等价于 **折打坐 ≤ 折挂机（比值 ≤ 1）**。
> · `P` = **投入品「变卖价」机会成本**（本表 = 纯修为草的**变卖价**，**不是**种子价）—— **口径与 T7 §3.5 一致**（c2-design 2026-09-29 裁定：可转卖投入品的真实代价 = 放弃的变卖收益）。
> · `H` = 当前境界挂机时薪 `rainHourlyStones`（炼气 23,568 ~ 长生 229,788）。
> · `G` = 折打坐 h = 该修为 ÷ 当前境界打坐时薪。
> **打坐时薪已实测到源码级**：`v = floor(F×10×(1+realmLevel×0.15))`（`index-v287-20260929.js` @660300 区 `RS()`），`F=[1,2,4,8,15,30,60]`，冷却 1 秒 ⇒ ×3600/h；按 T7 §3.4.4「**取 L1**」（最保守：打坐最慢 ⇒ 灵田最像捷径）。炼气 39,600 ~ 长生 2,484,000 修为/h。

**自查范围**：四条产品线 × 七境界全跑（各境界取可达最佳品阶）。**只有「纯修为草」一条线违规**，其余三线天然合规（比值 ≤ 0.34）——根因是纯修为草的「灵石/修为比」偏低。
