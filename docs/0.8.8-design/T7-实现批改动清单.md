## 2. 客户端改动（7 处 · 载体 `yl_t7legacy_ext.py`）

### §2.1 传承消耗核心 —— 整体重写（★ 本任务核心）

- **锚点**：`handleUseInheritance:()=>{` … 块尾 `return f})}`（**长 2,791 字符**，逐字全文见 §5 附录 A）
- **expect**：**1**
- **改法**：整体替换为「**逐点使用 + 分段效果**」新实现。逐字新代码见 §5 附录 B。

**语义（必须逐条落实）**：

| # | 规则 | 说明 |
|---|---|---|
| R1 | **一次只消耗 1 点** | `const v = f.inheritanceLevel \|\| 0; if (v <= 0) return f;` ⇒ **不存在「全部使用」路径** |
| R2 | 低境界（炼气/筑基/金丹，即 `idx <= 2`） | **推进 1 个小境界**（保留现状手感）；跨大境界时仍查 `ld()` |
| R2b | 高境界（元婴+，`idx >= 3`） | `exp = min(maxExp, exp + floor(ad(realm, realmLevel) * 0.25))`，**不推进 realm/realmLevel** |
| R2c | 高境界点击时 `exp >= maxExp` | 提示「当前修为已满，请先完成突破再引动传承。」，**不消耗点数**，`return f` |
| R3 | 高境界**不给**属性点、**不给**寿命、`breakthroughCount` 不 +1、不重算 `goldenCoreMethodCount` | **禁止复用整段重算逻辑**（这是本任务最易写错处） |
| R4 | 传承石路径补 `clamp` | 见 §2.4 |
| R5 | **去掉**「连续突破了 N 个境界」文案 | 见 §2.5 |

**新日志文案（逐字，§4.3 策划案）**：

| 场景 | 日志 |
|---|---|
| 低境界跳 1 层 | `🌟 你引动传承之力，修为突破，晋入 {realm}{level} 层！（剩余传承 {n} 点）` |
| 高境界注入 | `🌟 你引动传承之力，精纯修为涌入丹田（+{amount} 修为，{percent}%）。（剩余传承 {n} 点）` |
| 注入后刚好填满 | `✨ 修为已至圆满，只待突破！（剩余传承 {n} 点）` |
| 修为已满时点击 | `⚠️ 当前修为已满，请先完成突破再引动传承。（传承点数未消耗）` |
| 无传承点数 | `你尚未获得传承。` |
| 低境界跨大境界被 `ld()` 拦 | `传承突破中断：{message}（剩余传承 {n} 点已保留）` ← **补「已保留」提示，修 P7 体验问题** |
| 长生境 L9 满层 | `你已达到仙道巅峰，无法使用传承继续突破！` |

**关键实现约束**：

1. **必须**先算 `const idx = fe.indexOf(f.realm)`；`idx < 0` 时按低境界分支（安全兜底）。
2. 低境界分支的**大境界推进**必须复用现存的 `S+=1` 与 `ld()` 检查逻辑（原 `for` 循环体，但 `m` 初值固定为 **1**）。
3. **低境界分支保留**原有的属性点/寿命/属性重算（现状行为），因为那是**真的突破了**。
4. 高境界分支**只**动 `exp` 一个字段（+ 可能的 `maxExp` 同步），其余字段原样 `...f` 返回。
5. 高境界分支**必须**同步更新 `maxExp`：`ad(f.realm, f.realmLevel)`（原代码在突破后才更新 `maxExp`；不突破时 `maxExp` 不变，但为稳妥显式赋值同值）。

**伪代码（供实现对照，非逐字）**：

```js
handleUseInheritance:()=>{r(f=>{
  const v = f.inheritanceLevel || 0;
  if (v <= 0) { a("你尚未获得传承。","normal"); return f; }
  const idx = fe.indexOf(f.realm);
  const isLow = idx >= 0 && idx <= 2;         /* 炼气/筑基/金丹 */
  /* ---------- 高境界：修为注入 ---------- */
  if (!isLow) {
    const maxExp = ad(f.realm, f.realmLevel);
    const cur = f.exp || 0;
    if (cur >= maxExp) { a("⚠️ 当前修为已满，请先完成突破再引动传承。（传承点数未消耗）","danger"); return f; }
    const inj = Math.floor(maxExp * 0.25);
    const nx = Math.min(maxExp, cur + inj);
    const got = nx - cur;
    const pct = Math.floor(nx / maxExp * 100);
    a(nx >= maxExp
      ? `✨ 修为已至圆满，只待突破！（剩余传承 ${v-1} 点）`
      : `🌟 你引动传承之力，精纯修为涌入丹田（+${got} 修为，${pct}%）。（剩余传承 ${v-1} 点）`,
      "special");
    return { ...f, exp: nx, maxExp: maxExp, inheritanceLevel: v - 1 };
  }
  /* ---------- 低境界：原逻辑，m 固定 = 1 ---------- */
  let m = 1, j = 0, b = f.realm, S = f.realmLevel;
  /* ... 原 for(;m>0;) 循环体原样，改 m 初值 ... */
})}
```

> ★ **`isLow` 的边界必须严格是「炼气/筑基/金丹」三项**（对应 `fe` 下标 0/1/2），**元婴起（下标 ≥3）走注入**。不要写成 `idx <= 3`（会把元婴错判为跳层）。

  var day = (t.getUTCDay() + 6) % 7;                 /* 周一 = 0 */
  var mon = new Date(Date.UTC(t.getUTCFullYear(), t.getUTCMonth(), t.getUTCDate() - day, -8));
