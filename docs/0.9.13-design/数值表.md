## 1. 统一换算标准（R-119/R-130 共用）

**基准 = 加点面板**（bundle 内 `Ps` 表，`yl_attr097_ext.py:57` 锚点原文）：

```
Ps = { attack:15, defense:10, hp:100, spirit:3, physiqueHp:50, speed:2 }
```

⇒ **1 点加点 = 攻 15 / 防 10 / 血 100 / 神识 3 / 身法 2**（用户口径「1 点=3 神识、1 点=2 身法」与产物一致）。
本文所有「点当量」＝ 属性值 ÷ 对应单点值（神识÷3、身法÷2）。**设计目标：任何单件装备/单个天赋的特殊属性点当量，不得超过玩家该阶段总点数的一个可见小头。**

境界序（bundle `fe` 数组实读）：炼气期 → 筑基期 → 金丹期 → 元婴期 → 化神期 → 合道期 → 长生境（7 境）；总等级 = 境界序×9+层（rankings 口径，上限 63）。
装备等阶 T1..T7 与境界一一对应；装备稀有度 4 档：普通(白)/稀有(蓝)/传说(紫)/仙品(金)（bundle `Ba={普通:1,稀有:1.35,传说:2,仙品:3.2}`，**无「绿」档**，台账采样口径中的绿=普通）。

## 2. R-119【主表】全装备特殊属性重配

### 2.1 病根（产物证据）

随机/锻造装备生成器 `ZN(t,r,a)`（bundle @325575 实读）：

```
hm = { 普通:{attack:20,defense:20,hp:60,spirit:20,physique:20,speed:12},
       稀有:{...×3}, 传说:{...×7}, 仙品:{attack:300,...,spirit:300,...,speed:150} }   // 基础
u  = { 普通:{全 600}, 稀有:{全 1200}, 传说:{全 9000}, 仙品:{全 30000} }              // 上限（六项全等！）
槽位权重 m = { weapon:{attack:100, spirit:40, speed:30, ...},
               armor:{defense:100, spirit:5, speed:10, ...},
               accessory/ring:{spirit:100, speed:60, ...}, artifact:{spirit:100, ...} }
v = clamp( hm[R] + floor((10+a*5) × Ba[r] × m[slot][R] × (0.8+rand*0.4)), hm[R], u[R] )
```

⇒ **配件槽 spirit 权重 = 100 = 武器 attack 权重**，且上限表六项全等 ⇒ 神识与攻击同量级，这就是「炼气期神识 681」的根源（T1 白戒指 ≈ 20+10×1×100×roll ≈ **1,020 神识 = 340 点当量**，一只戒指 ≈ 炼气玩家半辈子加点）。
固定商店 13 件（iron-sword…仙剑·诛仙）实读 **全部不含 spirit/speed/百分比词条** ⇒ 无需改动。
丹药/灵草 permanentEffect 已由 R-107（R1 基础不减/R2 加点属性÷10）覆盖，本轮不动（观察项见 §14）。

### 2.2 新公式（替换 ZN 中 spirit/speed 两键的生成式；attack/defense/hp/physique **一律不动**）

```
spirit = round( SPB[T] × 品系数 × 槽系数 × (0.8 + rand×0.4) )
speed  = round( spirit × 2 / 3 )        // 点当量恒等（神 3/点、速 2/点）

SPB（等阶基）= [2, 4, 8, 16, 30, 55, 100]                    // T1..T7，≈×1.85/境
品系数       = { 普通:1.0, 稀有:1.4, 传说:2.0, 仙品:3.0 }      // 现值 {1,1.35,2,3.2}，金档略收
槽系数       = { 武器:0.5, 防具:0.5, 头/肩/腿/鞋/手:1.0, 戒指/饰品/法宝:2.5 }
```

设计语义：**戒指/饰品/法宝 = 神识主属性槽**（2.5x），武器/防具神识只是副词条（0.5x）；境界间差 ≈ ×1.85（大境界差拉开），稀有度间差 1→3（范围「略微扩大」由等阶基承担）。
